# sistem-panen-zeffanya

Proyek sederhana berbasis Python dan Git untuk mengelola data hasil panen serta kalkulasi diskon harga komoditas agroindustri.

## Deskripsi Singkat
Aplikasi ini dirancang untuk:
1. Menghitung total akumulasi hasil panen (dalam kg).
2. Menghitung pemotongan harga (diskon) secara otomatis berdasarkan persentase yang ditentukan.

## Cara Menjalankan Program
1. Pastikan Python 3.x sudah terpasang di perangkat Anda.
